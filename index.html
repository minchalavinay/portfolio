Deep Learning & Computer Vision

Sign Language Detection Using Deep Learning (CNN)

Project Problem & Objective

Bridging communication gaps for speech and hearing-impaired individuals requires rapid, accurate hand gesture translation. The goal was to design an end-to-end deep learning image classifier capable of recognizing diverse gestures in real-time under fluctuating lighting and angles.

Model Architecture & Engineering

The network is structured using TensorFlow/Keras with strategic regularization:

  • Conv2D Layer 1: 32 filters, 3×3 kernel size with ReLU activation for primitive edge and corner extraction.
  • MaxPooling2D: 2×2 pool size to downsample spatial dimensions while retaining invariant features.
  • BatchNormalization: Applied after convolution blocks to stabilize activations and accelerate convergence.
  • Dropout (0.25 & 0.5): Strategically dropped connections during training to prevent co-adaptation and eliminate overfitting.
  • Dense Softmax Output: Output layer with Softmax activation delivering multi-class probability distributions across hand signs.

Data Pipeline & Augmentation

Trained on 10,000+ hand gesture images. Applied ImageDataGenerator techniques including: rotations (up to 20°), zoom range (0.15), width/height shifts, and horizontal flips. This synthetic variation enabled the model to maintain 94% accuracy even on unseen camera angles.

Results & Real-Time Webcam Deployment

Achieved 94% test accuracy on holdout validation. An OpenCV script was built to capture 30 FPS video from webcams, crop bounding boxes, preprocess frames to 64×64 RGB, and render real-time predictions with <15ms latency.

NLP & Machine Learning

Email Spam Detection – NLP Classification Pipeline

Project Problem & Objective

Unsolicited spam emails cause security threats, phishing risks, and productivity loss. The project developed a fast, lightweight NLP classification pipeline capable of sorting legitimate emails from malicious spam with high precision and minimal false positives.

NLP Preprocessing Pipeline

Authored an automated text cleaning pipeline using NLTK:

  • Text Ingestion & Regex Cleaning: Stripped HTML tags, URLs, special characters, numbers, and excess whitespace.
  • Tokenization: Segmented sentences into individual word tokens.
  • Stop-word Removal: Filtered high-frequency uninformative words (e.g. "the", "is", "at") via NLTK corpus.
  • Stemming: Applied PorterStemmer to collapse words to their base root stems (e.g. "winning" → "win").
  • TF-IDF Vectorization: Calculated Term Frequency-Inverse Document Frequency scores to weight unique discriminative spam tokens.

Model Comparison & Results

Benchmarked Multinomial Naive Bayes against Gaussian Naive Bayes and Logistic Regression using 5-fold cross validation. Multinomial Naive Bayes yielded 96%+ test accuracy, 97% precision (crucial for avoiding false spam flags), and an ROC-AUC score of 0.98. Visualized results using Confusion Matrix and ROC curves in Seaborn.

Unsupervised Learning & Data Mining

Market Basket Analysis – Apriori Pattern Mining

Project Problem & Objective

Retailers need data-driven insights for product placement, bundle promotions, and inventory cross-docking. This project analyzed high-volume point-of-sale transactional datasets to reveal hidden co-purchasing affinities.

Data Pipeline & Algorithm Implementation

Connected to a MySQL transactional store. Extracted customer receipts, aggregated items per transaction, and converted data into a binary one-hot encoded matrix. Leveraged the Apriori algorithm via Python's mlxtend library to generate frequent itemsets based on minimum support thresholds.

Metrics & Business Rules

Computed key association metrics:

  • Support: Frequency of itemset occurrence across total basket orders.
  • Confidence: Probability that item Y is bought given that item X is in the basket.
  • Lift Ratio: Ratio of observed joint support to expected support if items were independent. Rules with Lift > 1.5 were prioritized for actionable marketing strategies.
